
Smart Applicant Shortlisting System (Resume Analyzer)

An AI-powered web application that analyzes resumes, extracts key information, and predicts suitable job roles using Natural Language Processing (NLP) and Machine Learning.

🚀 Features
📄 Upload resumes (PDF / TXT)
🤖 Automatic job category prediction
💼 Job recommendation system
🧠 Extracts:
Name
Email
Phone number
Skills
Education
✅ Resume validation (rejects non-resume files)
⚡ Fast and user-friendly UI
🛠️ Tech Stack
Backend: Python, Flask
Machine Learning: TF-IDF, Random Forest
NLP: Text preprocessing, keyword extraction
Frontend: HTML, CSS
🔄 How It Works
User uploads a resume (PDF/TXT)
Text is extracted from the file
NLP preprocessing is applied (cleaning, tokenization)
Resume is converted into vector form using TF-IDF
ML model predicts job category and recommends roles
Key information is extracted and displayed
